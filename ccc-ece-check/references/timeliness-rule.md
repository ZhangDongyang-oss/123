# 时效判定规则

## 核心规则

证书签发日距当前日期 **≤ 2年（24个月）** → ✅ PASS
证书签发日距当前日期 **> 2年（24个月）** → ⚠️ 提醒（证书签发日已超过2年）

## 计算方法

1. 取证书签发日（Date字段）
2. 取当前日期（系统时间）
3. 计算间隔月数 = (当前日期 - 签发日) 的月数
4. 比较 24个月

## 日期格式要求

**输入**：各种格式的日期字符串
- 英文：`01 January 2025` → `2025-01-01`
- 中文：`2025年01月01日` → `2025-01-01`
- 数字：`2025-01-01` → 原样

**输出**：统一用 `YYYY-MM-DD` 格式

## 判定结果分类

| 间隔 | 判定标签 | 后续动作（仅提示，DRE决策） |
|---|---|---|
| ≤ 24个月 | ✅ PASS | 无需处理 |
| > 24个月 | ⚠️ 证书签发日已超过2年 | 建议要求供应商提供新版证书 |

## 边界情况

| 情况 | 处理 |
|---|---|
| 签发日 = 当前日期（当天签发） | 间隔 = 0月 → PASS |
| 签发日缺失或无法识别 | 标"⚠️ 无法判定时效" → 不阻断流程，需人工复核 |
| 签发日早于2010年 | 极可能为旧版证书，建议即使在2年内也要复核 |

## 不校核的日期（仅记录不判定）

- ECE最新测试日（P13 Test date最后一行）
- ECE历次展期日（P2-P3的日期列表）
- CCC附件中各车型的具体检验日期

这些日期可能在综合判定时备注，但**不参与**"是否在效期"的判定。
