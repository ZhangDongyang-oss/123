## v2.4.0 (2026-08-18) — 内外镜全线对齐 + 多文件上传 + SR 交叉验证

### 新增
- 镜片**轮廓度**参数（对称 ±mm，车型可配，缺省 0.3）：距边 < 轮廓度判「可能超出加工边界」，视图加工边界带 + 判据卡标注
- **多文件上传合并**：同一车型多个 STEP 自动合并提取（内外镜都支持，`parse_and_merge` 移公共层）
- **SR 交叉验证**：提取时几何实测半径 vs 标称值（默认 1260±60），偏差超公差汇报、人工判断（不阻断）
- 标注要求定稿：镜体坐标系三轴 / 镜片 CAS 面 / SR 参数 / 参考地平线；内镜标注对齐（球铰旋转中心 / 镜心几何中心 / 反射 CAS 面）
- 内外镜界面对齐：内镜标题加 (I 类)、角度卡统一「调节角度」、**单位统一 mm**、地面术语统一「参考地平线前端/后端中点」、删外镜死按钮

### 修复
- 外镜轮廓提取补 `strip_doubled_paths`，清 CAD 退化环毛刺/飞线（左 421→293 点）
- 修 `spawnStepExtract` failure 回调 `res.status(string)` 崩服务（上传空文件触发）
- 搜角种子命中后不再提前返回：补全热图 grid + 完整 PASS 区域（种子优先保留）
- 视图 `layout.height` 显式化（不再依赖容器 CSS 高度），修复 车型A 后挡风图例不显示

### 引擎
- 170 断言全绿（166 + 轮廓度 2 + 搜角回归 2）

## v2.0.0 (2026-08-14) — 内外镜全自动 STEP 提取工作流

> 重大里程碑:从「手动取点 / 3DE 选点」升级为「上传一个整车 STEP 全自动提取全部校核参数」。

### 重大变更 (工作流重构)
- **外镜**: 上传整车 STEP → 球面/轮廓/球心/R 几何识别 + 旋转轴 AXIS2_PLACEMENT_3D 结构识别 + 6 命名点 → 全自动
- **内镜**: 上传整车 STEP → 镜片面/后挡风命名识别 + 球铰/镜心命名点 + yaw/pitch SVD 推导 → 全自动
- **二维调节校核**: 外镜从单轴(上下 ψ)升级为二维(上下 ψ × 左右 θ, 各 ±3°), 符合 GB 15084 法规「初始不满足可上下+左右调节后校核」

### 新增
- 外镜 STEP 一键提取 + 上传校核闭环 (stage 0-6)
- 内镜 STEP 一键提取 + 工作流重构 (stage 7)
- 大文件上传鲁棒性: 流式写盘防 OOM + 上传进度 + 失败重试不重传 + JSON 错误处理 (stage 8)
- 内外镜存储统一: 轮廓 inline + 单接口原子保存 + 缺参阻止 (stage 9)
- 命名中文化 (眼点左/球铰/镜心/后挡风 等, 旧英文名兼容) (stage 10)
- 自动搜角二维化: 应用 psi + theta (stage 12)
- UI 精简: 向导一步化 + 校核页参数折叠 + 摘要紧凑表格 (stage 13)
- 供应商 STEP 数据规范 (内外镜合并版, 中文命名, 车门蒙皮口径已确认)

### 修复
