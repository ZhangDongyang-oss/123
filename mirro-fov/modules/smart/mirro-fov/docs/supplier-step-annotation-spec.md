# 供应商 STEP 标注规范 (内/外后视镜合并版)

> 目的:供应商按本规范在**一个 STEP 文件**里标注/准备好数据,系统上传后**全自动提取**校核所需全部参数,无需人工选点。
> 合并自 `exterior-step-supplier-spec.md`(外镜)与 `interior-step-supplier-spec.md`(内镜)。
> 制定:2026-08-13。坐标系:整车 X+后 / Y+右 / Z+上 / LHD,单位 mm。

## 一、标注类别总览

供应商需在 STEP 里提供 4 类数据。识别方式三种:**几何识别**(靠曲面类型)、**结构识别**(靠坐标系实体)、**命名识别**(赋固定名)。

> ⚠️ **重要:下表每一项都是"必须提供"的数据。"识别方式"只说明系统怎么找到它,不等于"可以不提供"。** 供应商漏任何一项(球面/坐标系/命名点/命名面)都会导致提取失败、需返工。

| 类别 | 外镜(III 类,凸球面) | 内镜(I 类,平面) | 必须提供 |
|---|---|---|---|
| ① 镜面几何面 | `SPHERICAL_SURFACE`(命名 `镜片左/右` 优先) | `ADVANCED_FACE` 平面(命名 `镜片`) | ✅ 必须 |
| ② 镜体结构 | `AXIS2_PLACEMENT_3D`(命名 `旋转轴左/右`) | 无结构,用命名点替代 | ✅ 必须(外镜) |
| ③ 命名参考点 | 6 个 `CARTESIAN_POINT` | 6 个 `CARTESIAN_POINT` | ✅ 必须 |
| ④ 命名面 | 无 | 1 个 `ADVANCED_FACE`(后挡风) | ✅ 必须(内镜) |

## 二、外镜(III 类)标注清单

### ① 镜面几何 — 必须提供,建议命名 `镜片左`/`镜片右`
- 左右各 1 个 `SPHERICAL_SURFACE`(凸球面)。**必须提供。**
- **建议命名 `镜片左`/`镜片右`**:系统直接按名定位,避免整车 STEP 多个球面时误识。
- 兜底:未命名时系统按球心 Y 正负分左右(左 Y<0,右 Y>0),追踪边界得轮廓,取球心 + R。

### ② 镜体坐标系 — 必须提供,命名 `旋转轴左`/`旋转轴右`
- 左右各 1 个 `AXIS2_PLACEMENT_3D`,放置点 = turret p1(旋转中心)。**必须提供。**
- 三轴 = 镜体局部坐标系:Z=折叠轴(≈整车 Z)、X=右向、Y=旋转轴(系统算 Z×X)。
- **命名 `旋转轴左` / `旋转轴右`**(旧名 `MIRROR_FRAME_LEFT`/`MIRROR_FRAME_RIGHT` 兼容;命名用于系统直接定位,避免误判)。
- 系统按名直取(优先),fallback 结构识别(排除原点世界系 + 按放置点 Y 分左右 + 自动判定 fold/tilt)。
- 提取:turret_axis_p1(放置点)、rotation_axis_dir(旋转轴)。

### ③ 命名参考点 — 必须提供 + 必须命名
6 个 `CARTESIAN_POINT`,固定名(中文新名;旧英文名兼容):

| 点名(主) | 旧名(兼容) | 含义 |
|---|---|---|
| `眼点左` | `EYE_LEFT` | 左眼点 |
| `眼点右` | `EYE_RIGHT` | 右眼点 |
| `地面前` | `GROUND_FRONT` | 地面参考线前端中点 |
| `地面后` | `GROUND_REAR` | 地面参考线后端中点 |
| `车门左` | `DOOR_OUTER_LEFT` | 左车门**蒙皮主面**最外点(取 Y) |
| `车门右` | `DOOR_OUTER_RIGHT` | 右车门**蒙皮主面**最外点(取 Y) |

> 车门最外点口径已确认:车门蒙皮主面(非车身包络/含凸出)。参考实测:左 [558.585,-1005.238,397.951] / 右 [558.585,1005.238,397.951]。

## 三、内镜(I 类)标注清单

### ① 镜面几何面 — 必须提供 + 命名 `镜片`(平面无几何唯一性)
- 镜片面命名 `镜片`(旧名 `INNER_MIRROR_GLASS`)(`ADVANCED_FACE`,平面)。**必须提供。**
- 兜底:若未命名,系统在 pivot/center_zero 附近 200mm 找最大平面。
- 提取:镜面轮廓 → width/height;镜面法向 → yaw/pitch。
- **供应商需保证**:镜片面是平面,且命名 `镜片`。

### ② 镜体结构 — 无(用命名点替代)
内镜是 yaw/pitch 双角调节,无单一旋转轴结构;pivot/center_zero 用命名点提供。

### ③ 命名参考点 — 必须提供 + 必须命名
| 点名(主) | 旧名(兼容) | 含义 |
|---|---|---|
| `球铰` | `MIRROR_PIVOT` | 镜片球铰中心(pivot) |
| `镜心` | `MIRROR_CENTER_ZERO` | 镜面 yaw=pitch=0 时的中心点 |
| `眼点左` / `眼点右` | `左侧眼椭圆中心点` / `右侧眼椭圆中心点` | 左/右眼(→ IPD) |
| `眼椭圆` | — | 眼中心(车型C 已有命名习惯,兼容) |
| `地面前` | `GROUND_FRONT` | 地面前端 |
| `地面后` | `GROUND_REAR` | 地面后端 |

### ④ 命名面 — 必须提供 + 命名 `后挡风`
| 面名(主) | 旧名(兼容) | 含义 |
|---|---|---|
| `后挡风` | `REAR_WINDOW` | 后挡风 CAS 外框面 → 7 点轮廓 |
| `透光区` | `REAR_WINDOW_TZ` | 后挡风透光区面 → 4 点透光区(**暂不需要,可选**) |

## 四、对比要点

| | 外镜 | 内镜 |
|---|---|---|
| 镜面识别 | 球面几何唯一(易) | 平面需命名(平面无唯一性) |
| 关键结构参数 | 旋转轴(AXIS2_PLACEMENT_3D 结构) | pivot/center_zero(命名点,无结构) |
| 调节参数 | ψ 单轴 | yaw/pitch 双角(法向推导) |
| 后挡风 | 不需要 | 需要(2 命名面) |
| 车门最外 | 需要(2 命名点) | 不需要 |
| 命名点数 | 6 | 4+(眼点可沿用中文命名) |
| 命名面数 | 2(镜片左/右,建议) | 3(镜片 + 后挡风外框 + 透光区) |

## 五、供应商自检清单

**外镜 STEP**:
- [ ] 2 个 `SPHERICAL_SURFACE`(左右凸球面镜片),建议命名 `镜片左`/`镜片右`
- [ ] 2 个 `AXIS2_PLACEMENT_3D` 放 turret p1(Z≈整车 Z),**命名 `旋转轴左` / `旋转轴右`**
- [ ] 6 命名点:`眼点左` `眼点右` `地面前` `地面后` `车门左` `车门右`(旧名 `EYE_LEFT` 等兼容)

**内镜 STEP**:
- [ ] 镜片面命名 `镜片`(旧名 `INNER_MIRROR_GLASS`)
- [ ] 命名点:`球铰` `镜心` `眼点左`/`眼点右`(或 `眼椭圆`/`左右眼椭圆中心点`)`地面前` `地面后`
- [ ] 命名面:`后挡风`(`透光区` 暂不需要,可选)

满足以上,系统上传该 STEP 即可全自动提取全部校核参数,无需任何人工输入。

## 六、命名规则

- STEP 实体名(实体第一个参数,单引号字符串)。
- 统一用简洁中文新名(见上表):外镜 `眼点左`/`眼点右`/`地面前`/`地面后`/`车门左`/`车门右` + 镜体坐标系 `旋转轴左`/`旋转轴右`;内镜 `球铰`/`镜心`/`镜片`/`后挡风`(`透光区` 暂不需要) + 眼点沿用 `眼点左`/`眼点右`。
- 旧名兼容:英文(`EYE_LEFT` 等)与 车型C 中文(`眼椭圆`/`左右眼椭圆中心点`)仍能识别,不强制重导。
- 命名缺失时:外镜眼点/地面/车门、内镜眼点/地面有启发式兜底(仅适用本车型,不可靠);内镜 pivot/center_zero/后挡风无兜底,缺则该项为空、保存被阻止;`透光区` 缺失时系统自动用后挡风外框兜底(不阻止保存)。
