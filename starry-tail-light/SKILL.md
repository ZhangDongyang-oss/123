# 星空尾灯动画AI - 数字孪生动画设计系统

## 概述

本系统是一个基于 Canvas 的某车企 车型A Ultra 星空尾灯数字孪生动画设计器，对尾灯的 230 颗 LED 进行实时动画模拟，支持多种内置效果、AI 智能生成、自然语言交互及多段时序编排。

## 核心功能

| 功能 | 说明 |
|------|------|
| 🎨 内置效果 | 10 种预设灯光动画效果，可独立调参 |
| 🤖 AI 动画 | 接入大语言模型，用自然语言描述生成任意动画 |
| 💬 自然语言 | 输入中文描述自动匹配最佳效果并调参 |
| ⏱ 多段时序 | 用时序语法编排多段动画自动切换 |
| 🔥 热力图 | 可视化各 LED 颗粒的平均亮度分布 |
| ⛶ 全屏模式 | 沉浸式全屏预览动画 |
| 📷 截图导出 | 一键将当前画面保存为 PNG 图片 |
| 💾 存档系统 | 保存 / 加载自定义参数配置 |
| 🔗 URL 分享 | 生成参数分享链接，可直接打开 |
| 🎛 参数面板 | 速度、尾长、亮度、密度等精细调节 |
| 🎨 分组配色 | 为不同 LED 区域设置独立颜色 |
| 🔍 缩放平移 | 鼠标滚轮缩放 + 拖拽平移画布 |

## 使用流程

1. **打开页面**：在浏览器中打开 `星空尾灯动画AI.html`
2. **选择效果**：在首页效果卡片网格中点击任一动画效果进入预览界面
3. **调节参数**：通过右侧参数面板的滑块实时调整动画参数
4. **AI 生成**（可选）：在 AI 动画面板输入中文描述，点击生成
5. **时序编排**（可选）：在多段时序面板输入时序语法，自动播放多段动画
6. **导出**：使用截图功能或分享链接保存成果

## AI 动画配置

使用 AI 动画功能前需要配置 API Key：

1. 展开右侧面板的「🤖 AI 动画面板」
2. 输入 Ollama 兼容 API 的 Key
3. 在文本框中用中文描述想要的动画效果
4. 点击「✨ 生成」按钮

AI 会将自然语言描述转化为包含多个 track 的灯光时间轴，每个 track 可独立控制不同效果、位置和时间。

## 自然语言示例

```
快速闪烁的红色流星
蓝色波浪从中间向两边扩散
呼吸灯，节奏慢一点
5颗流星交错划过，速度加快
```

## 时序语法

格式：`效果名称 + 时长`，多个段落用逗号分隔。

示例：
```
中心分流3秒，流星雨5秒，呼吸4秒
波浪扩散6秒，追逐8秒
```

系统会自动解析效果名称和时长，启动多段动画自动切换，支持段间丝滑 crossfade 过渡。
