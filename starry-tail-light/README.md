# 星空尾灯动画AI 使用指南

> **说明**：本仓库为脱敏版本——实车照片等图片素材已替换为占位图；云端大模型已改为本地
> [Ollama](https://ollama.com)（OpenAI 兼容接口 `http://localhost:11434/v1`，默认模型 `qwen2.5:7b`）。
> 直接用浏览器打开 `星空尾灯大屏版.html` 即可体验；历史版本见 `archive/`。

## 简介

**星空尾灯动画AI** 是一款某车企 车型A Ultra 星空尾灯的数字孪生动画设计系统。通过 Canvas 实时渲染 230 颗 LED 灯珠，支持内置效果选择、参数精细调节、AI 自然语言生成动画、多段时序编排等功能。

---

## 快速开始

### 第一步：打开系统

在浏览器中直接打开 `星空尾灯动画AI.html` 文件即可，无需安装任何依赖。

### 第二步：选择动画效果

打开后会看到首页，展示 10 种内置动画效果的卡片：

- 每张卡片包含效果图标、名称和简要描述
- 点击任意卡片即可进入该效果的预览界面
- 卡片支持悬浮高亮动效，选中后有红色边框提示

### 第三步：预览与调节

进入预览界面后：

- **左侧画布**：实时渲染 230 颗 LED 的动画效果
- **右侧参数面板**：通过滑块实时调节动画参数
- **播放/暂停**：点击播放按钮或按 `Space` 键
- **时间轴**：拖动进度条跳转到任意时间点

## 功能详解

### 🎨 内置效果

系统内置 10 种精心设计的灯光动画效果，每种效果有独立的可调参数：

**中心分流 (centerSplit)**
- 从 LOGO 位置向两侧水平流动
- 参数：流速、彗尾长度、亮度

**波浪扩散 (wave)**
- 从中心向外产生的涟漪波纹效果
- 参数：波速、波宽、波数（1-8 个波）、底光亮度

**流星雨 (meteor)**
- 多颗流星在灯带上交错划过
- 参数：速度、尾长、束宽、数量（1-8 颗）、底光

**单颗流星 (singleMeteor)**
- 一颗明亮流星划过夜空的效果
- 参数：速度、尾长、束宽、亮度、底光

**呼吸 (breath)**
- 全灯带柔和的明暗呼吸效果
- 参数：周期（0.5-12 秒）、最暗亮度、最亮亮度

**追逐 (chase)**
- 光点沿椭圆轨迹旋转追逐
- 参数：转速、拖尾长度、光点数量（1-8）、底光

**星空闪烁 (sparkle)**
- 满天星斗随机闪烁的效果
- 参数：闪烁密度、速度、底光

**三层波浪 (layerWave)**
- 里中外三层依次点亮熄灭
- 参数：层数（2-5）、波速、波宽、相位差、底光

**波浪分流 (waveSplit)**
- 三层波浪与水平分流效果融合
- 参数：波速、波宽、波数、底光、分流速度、分流彗尾

**椭圆跑马灯 (marquee)**
- 里中外三层椭圆轨迹跑马灯
- 参数：环跑速度、环跑尾长、竖扫速度、竖扫尾宽、底光

### 🤖 AI 动画生成

接入 Ollama 兼容的大语言模型，用自然语言描述即可生成任意复杂动画。

**配置步骤：**
1. 在右侧参数面板找到「🤖 AI 动画」区块
2. 在 Key 输入框填入你的 API Key
3. 点击「保存」按钮

**使用方法：**
1. 在文本框中用中文描述想要的动画效果
2. 点击「✨ 生成」按钮
3. 等待 AI 生成动画时间轴（约 5-15 秒）
4. 生成完成后自动进入 AI 动画模式

**AI 生成的动画包含：**
- 多个独立 track（轨道）
- 每个 track 可指定不同效果和位置
- 支持时间区间控制
- 支持效果叠加和混合

---

### 💬 自然语言生成（离线可用）

无需 API Key，通过内置规则引擎将中文描述转化为动画效果。

**支持的描述方式：**
- 效果名称：`流星雨`、`呼吸灯`、`波浪`
- 颜色描述：`红色`、`蓝色`、`蓝色波浪`
- 速度描述：`快速闪烁`、`慢速呼吸`
- 组合描述：`快速闪烁的红色流星`

**使用方法：**
1. 找到「◈ 自然语言生成」面板
2. 输入中文描述
3. 按回车或点击生成按钮
4. 系统自动匹配最佳效果并应用参数

---

### ⏱ 多段时序编排

支持多段动画按时间顺序自动切换播放。

**语法格式：**
```
效果名称 + 时长（秒）
```

**示例：**
```
中心分流3秒，流星雨5秒，呼吸4秒
波浪扩散6秒，追逐8秒，星空闪烁3秒
```

**使用方法：**
1. 找到「⏱ 多段时序」面板
2. 输入时序描述
3. 点击启动
4. 系统自动解析并按顺序播放各段动画
5. 段间自动进行丝滑 crossfade 过渡

---

### 🔥 热力图模式

可视化各 LED 颗粒在一段时间内的平均亮度分布。

- 按 `H` 键或点击「🔥 热力图」按钮切换
- 红色区域表示高亮度，蓝色表示低亮度
- 用于分析动画的亮度覆盖和视觉焦点

---

### ⛶ 全屏模式

进入沉浸式全屏预览，隐藏所有 UI 元素。

- 按 `F` 键或点击「⛶ 全屏」按钮
- 按 `Esc` 键退出全屏

---

### 📷 截图导出

将当前画面导出为 PNG 图片。

- 按 `P` 键或点击「📷 截图」按钮
- 自动下载为 `tailight-screenshot.png` 文件

---

### 💾 存档系统

保存和加载自定义的参数配置。

**保存配置：**
1. 点击「💾 保存」按钮
2. 当前效果名称和所有参数自动保存到浏览器

**加载配置：**
1. 点击「📂 加载」按钮
2. 选择之前保存的配置
3. 参数自动恢复

---

### 🔗 URL 分享

生成包含当前参数的 URL 链接，分享给他人直接打开。

- 点击「🔗 分享」按钮
- 链接自动复制到剪贴板
- 打开链接直接恢复到分享时的参数状态

---

### 🎛 参数面板

每个效果都有独立的参数调节面板，所有参数都支持实时预览：

| 参数类型 | 说明 |
|----------|------|
| 速度类 | 动画播放快慢（speed） |
| 长度类 | 尾巴、光束的长度（tail, beam） |
| 亮度类 | 灯光亮度（bright, maxB） |
| 密度类 | 闪烁、星星的密度（density） |
| 数量类 | 光点、波浪的数量（count） |
| 底光 | 整体基础亮度（base） |

每个参数旁显示当前数值，可通过滑块或直接点击重置按钮恢复默认值。

---

### 🎨 分组独立配色

为不同 LED 区域（里圈、中圈、外圈）设置独立颜色。

- 在「🎨 分组配色」面板中分别设置颜色
- 支持 3 组独立配色
- 颜色变化实时应用到对应区域的 LED

---

### 🔍 缩放与平移

对画布进行缩放和平移，便于观察细节。

- **滚轮缩放**：鼠标滚轮向上放大、向下缩小
- **拖拽平移**：按住鼠标左键拖拽移动画布
- **双击重置**：双击画布恢复到默认视角

---

## 技术细节

- **渲染引擎**：HTML5 Canvas 2D
- **LED 数量**：230 颗（3 圈布局：里圈、中圈、外圈）
- **刷新率**：60fps（requestAnimationFrame）
- **AI 接口**：Ollama 兼容 API（Ollama LLM）
- **存储**：localStorage 存储配置和 API Key
- **依赖**：零外部依赖，单 HTML 文件即可运行

---

## 注意事项

- AI 动画功能需要配置有效的 API Key
- 自然语言生成功能离线可用，无需网络
- 存档数据保存在浏览器中，清除浏览器数据会丢失
- URL 分享链接包含完整参数，长度较长
- 全屏模式在部分浏览器中可能需要用户授权
