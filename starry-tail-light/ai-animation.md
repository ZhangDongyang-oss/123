# AI 动画功能使用指南

本文档详细介绍如何使用 AI 动画生成功能，将自然语言描述转化为专业的灯光动画时间轴。

---

## 功能概述

AI 动画功能接入 Ollama 兼容的大语言模型（Ollama LLM），能够理解中文描述并将其转化为包含多个 track（轨道）的灯光动画时间轴。每个 track 可以独立控制不同的效果、位置和时间区间，实现复杂而专业的动画编排。

---

## 配置要求

### API 配置

需要一个 Ollama 兼容的 API 服务，支持以下接口格式：

```
POST /api/chat
Content-Type: application/json
Authorization: Bearer <your-api-key>

{
  "model": "qwen2.5:7b",
  "messages": [...],
  "stream": false
}
```

### 获取 API Key

1. 访问你的 Ollama 服务提供商
2. 在账户设置或 API 管理页面获取 Key
3. Key 通常以 `sk-` 或类似格式开头

---

## 配置步骤

### 第一步：找到 AI 动画面板

在右侧参数面板中，找到「🤖 AI 动画」区块。如果面板折叠，点击标题展开。

### 第二步：输入 API Key

1. 在 Key 输入框中粘贴你的 API Key
2. 点击「保存」按钮
3. 系统会将 Key 保存到浏览器本地存储，下次打开自动加载

### 第三步：验证配置

配置完成后，面板底部会显示状态信息：
- 绿色文字：配置成功
- 红色文字：配置错误，请检查 Key 是否正确

---

## 使用方法

### 基本流程

1. **输入描述**：在文本框中用中文描述想要的动画效果
2. **点击生成**：点击「✨ 生成」按钮
3. **等待生成**：AI 会花 5-15 秒分析描述并生成动画
4. **自动播放**：生成完成后自动进入 AI 动画模式并开始播放

### 描述技巧

**好的描述应该包含：**

- **效果类型**：流星、波浪、呼吸、闪烁、追逐等
- **颜色信息**：红色、蓝色、暖白、冷白等
- **运动特征**：从左到右、从中心向外、快速、缓慢等
- **时间长度**：持续时长或循环周期
- **叠加效果**：多个效果同时或交替出现

**示例描述：**

```
红色流星从左到右划过，后面跟着蓝色波浪扩散，持续10秒
```

```
先呼吸3秒，然后5颗流星交错划过，最后星空闪烁5秒
```

```
快速闪烁的红色光点，从中心向四周扩散
```

```
蓝色椭圆跑马灯，配合绿色呼吸效果
```

## 生成结果

### 时间轴结构

AI 生成的动画包含一个或多个 track（轨道），每个 track 具有以下属性：

| 属性 | 说明 |
|------|------|
| effect | 使用的效果类型（内置效果 ID） |
| start | 开始时间（秒） |
| end | 结束时间（秒） |
| region | 作用区域（center, inner, middle, outer, left, right, all） |
| params | 该 track 的独立参数配置 |
| weight | 效果权重（0-1），控制主次关系 |

### 效果类型

AI 可以使用以下内置效果：

| 效果 ID | 名称 | 适用场景 |
|---------|------|----------|
| centerSplit | 中心分流 | 迎宾、启动仪式 |
| wave | 波浪扩散 | 水波、涟漪效果 |
| meteor | 流星雨 | 流星、快速光点 |
| singleMeteor | 单颗流星 | 强调、引导 |
| breath | 呼吸 | 柔和、温馨氛围 |
| chase | 追逐 | 动感、赛跑 |
| sparkle | 星空闪烁 | 浪漫、星空 |
| layerWave | 三层波浪 | 层次推进 |
| waveSplit | 波浪分流 | 复杂混合效果 |
| marquee | 椭圆跑马灯 | 旋转、环绕 |

### 作用区域

| 区域 | 说明 |
|------|------|
| all | 整个灯带 |
| center | 中心区域（LOGO 附近） |
| inner | 里圈 |
| middle | 中圈 |
| outer | 外圈 |
| left | 左半部分 |
| right | 右半部分 |

## 高级功能

### 多 Track 叠加

AI 可以生成多个同时运行的 track，实现效果叠加：

```json
{
  "duration": 10,
  "tracks": [
    {
      "effect": "breath",
      "start": 0,
      "end": 10,
      "region": "all",
      "params": {"period": 3, "minB": 0.05, "maxB": 0.6},
      "weight": 0.4
    },
    {
      "effect": "sparkle",
      "start": 0,
      "end": 10,
      "region": "outer",
      "params": {"density": 0.2, "speed": 1.5},
      "weight": 0.8
    }
  ]
}
```

这个例子中：
- 背景是柔和的呼吸效果（权重 0.4，作为辅助）
- 外圈叠加星空闪烁效果（权重 0.8，作为主效果）

### 时间编排

Track 可以按时间顺序编排，实现复杂的动画叙事：

```json
{
  "duration": 15,
  "tracks": [
    {"effect": "breath", "start": 0, "end": 5, "region": "all", ...},
    {"effect": "centerSplit", "start": 5, "end": 10, "region": "all", ...},
    {"effect": "meteor", "start": 10, "end": 15, "region": "all", ...}
  ]
}
```

这个例子实现了：
- 0-5 秒：呼吸效果开场
- 5-10 秒：中心分流过渡
- 10-15 秒：流星雨高潮

### 权重控制

`weight` 参数控制 track 的主次关系：

- **主效果**：weight 0.8-1.0，视觉焦点
- **辅助效果**：weight 0.3-0.6，背景烘托
- **点缀效果**：weight 0.1-0.3，细节补充

系统会自动根据权重进行亮度混合，权重高的效果更明显。

## 常见问题

### Q: 生成失败怎么办？

**可能原因：**
- API Key 无效或过期
- 网络连接问题
- AI 服务暂时不可用

**解决方法：**
1. 检查 API Key 是否正确
2. 检查网络连接
3. 稍后重试
4. 查看面板底部的错误提示

### Q: 生成的动画不符合预期？

**改进方法：**
- 使用更具体的描述
- 明确指出颜色、方向、速度
- 分步骤描述复杂动画
- 尝试不同的描述方式

### Q: 生成速度很慢？

**优化建议：**
- 简化描述长度
- 减少同时要求的效果数量
- 检查网络速度
- 选择更快的 API 服务

### Q: 如何退出 AI 动画模式？

先暂停再点击任意内置效果卡片即可退出 AI 模式，回到普通效果预览。

**用户输入：**
```
车辆迎宾灯光秀，先从 LOGO 向两侧分流，然后波浪扩散，最后呼吸效果淡出
```

**AI 生成：**

**用户输入：**
```
蓝色星空闪烁作为背景，中间偶尔划过红色流星，整体偏暗有氛围感
```

**AI 生成：**
- Track 1 (0-10s): sparkle，全区域，蓝色，密度 0.15，weight 0.4
- Track 2 (0-10s): singleMeteor，随机触发，红色，weight 0.9

### 示例 3：动感节拍

**用户输入：**
```
快速节奏，3颗光点追逐，配合闪烁效果，每2秒一次爆发
```

**AI 生成：**
- Track 1 (0-10s): chase，转速 1.5，3 光点，weight 0.7
- Track 2 (0-10s): sparkle，密度 0.3，速度 2，weight 0.5
- Track 3 (0-10s): meteor，每 2 秒触发一次，weight 0.9

## 技术限制

- AI 生成结果依赖模型质量，不同模型效果可能有差异
- 生成的参数范围受内置效果限制
- 过于复杂的描述可能导致生成结果不理想
- 建议使用简洁明确的中文描述
