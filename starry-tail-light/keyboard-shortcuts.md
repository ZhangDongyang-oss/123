# 快捷键参考

本文档列出所有可用的键盘快捷键，便于快速操作。

---

## 播放控制

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Space` | 播放 / 暂停 | 切换动画的播放状态，同时更新播放按钮图标 |

**使用场景：**
- 预览效果时快速暂停观察细节
- 播放/暂停切换时无需移动鼠标

---

## 视图切换

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `H` | 切换热力图 | 在普通视图和热力图视图之间切换 |
| `F` | 全屏模式 | 进入或退出全屏沉浸式预览 |

### 热力图模式 (H)

按 `H` 键切换到热力图模式，可视化各 LED 颗粒在一段时间内的平均亮度分布。

**热力图颜色含义：**
- 🔴 红色区域：高亮度，视觉焦点
- 🟡 黄色区域：中等亮度
- 🔵 蓝色区域：低亮度
- ⚫ 黑色区域：基本熄灭

**使用场景：**
- 分析动画的亮度分布是否均匀
- 检查视觉焦点是否在预期位置
- 优化动画参数使效果更均衡
- 对比不同效果的亮度覆盖

**切换方法：**
- 按 `H` 键
- 或点击顶部工具栏的「🔥 热力图」按钮

### 全屏模式 (F)

按 `F` 键进入全屏沉浸式预览模式。

**全屏模式特点：**
- 隐藏所有 UI 元素，只显示动画画布
- 黑色背景，最大化视觉沉浸感
- 保留星空背景动画
- 支持鼠标滚轮缩放和拖拽平移

**退出方法：**
- 按 `Esc` 键
- 或按 `F` 键
- 或点击浏览器的退出全屏按钮

**使用场景：**
- 最终效果预览
- 演示给他人观看
- 录屏或截图前的准备
- 沉浸式体验动画效果

## 导出功能

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `P` | 截图导出 | 将当前画面保存为 PNG 图片 |

### 截图导出 (P)

按 `P` 键将当前画布内容导出为 PNG 图片。

**导出详情：**
- 文件名：`tailight-screenshot.png`
- 格式：PNG（无损压缩）
- 分辨率：与画布当前尺寸一致
- 保存位置：浏览器默认下载文件夹

**使用场景：**
- 保存喜欢的动画瞬间
- 用于设计文档或汇报材料
- 分享给团队成员参考
- 记录不同参数下的效果对比

**操作步骤：**
1. 播放动画到想要的画面
2. 按 `Space` 暂停
3. 按 `P` 键截图
4. 图片自动下载到本地

## 使用技巧

### 组合使用

**效果预览流程：**
1. 选择效果 → 开始播放
2. 按 `Space` 暂停在关键帧
3. 按 `H` 查看热力图分布
4. 调整参数后按 `Space` 继续播放
5. 满意后按 `F` 全屏预览
6. 按 `P` 截图保存

**对比分析流程：**
1. 效果 A：暂停 → 按 `H` 查看热力图 → 按 `P` 截图
2. 效果 B：暂停 → 按 `H` 查看热力图 → 按 `P` 截图
3. 对比两张截图的亮度分布

### 注意事项

- 快捷键在文本输入框中不会生效（避免干扰输入）
- 全屏模式下按 `Esc` 退出
- 截图时动画会暂停，便于精确截取
- 热力图数据需要播放一段时间后才有意义

## 鼠标操作

除了键盘快捷键，还支持以下鼠标操作：

| 操作 | 功能 | 说明 |
|------|------|------|
| 滚轮上滚 | 放大画布 | 以鼠标位置为中心放大 |
| 滚轮下滚 | 缩小画布 | 以鼠标位置为中心缩小 |
| 左键拖拽 | 平移画布 | 按住左键拖拽移动视图 |
| 双击 | 重置视图 | 恢复到默认的缩放和平移状态 |

**使用场景：**
- 放大观察某个区域的 LED 细节
- 平移查看灯带的不同部分
- 双击快速回到默认视角

---

## 触控板支持

在笔记本触控板上：

- **双指上下滑动**：等同于滚轮，用于缩放
- **单指按住拖拽**：等同于左键拖拽，用于平移
- **双指点击**：部分系统等同于双击，用于重置视图

---

## 浏览器兼容性

所有快捷键在以下浏览器中测试通过：

- ✅ Google Chrome (推荐)
- ✅ Microsoft Edge
- ✅ Mozilla Firefox
- ✅ Safari

**已知问题：**
- 某些浏览器的全屏模式可能需要用户授权
- Firefox 的全屏 API 行为略有不同
- Safari 在某些情况下热力图渲染可能有延迟

## 自定义快捷键

当前版本暂不支持自定义快捷键。如需修改，可编辑 HTML 文件中的 JavaScript 代码：

```javascript
document.addEventListener('keydown', function(e) {
  // 在此修改快捷键绑定
  if (e.code === 'Space') { /* ... */ }
  if (e.code === 'KeyH') { /* ... */ }
  if (e.code === 'KeyF') { /* ... */ }
  if (e.code === 'KeyP') { /* ... */ }
});
```
