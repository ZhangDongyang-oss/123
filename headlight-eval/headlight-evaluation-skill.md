# 前照灯主观评价技能（远近光一体）

## 触发条件

当用户描述近光灯/远光灯的实际表现（实物图、伪彩图），并要求进行主观评分、评级、打分、对标比较，或生成灯光评价报告时，使用此技能。

---

## 适用场景

- 快速灯光主观评价
- 多灯横向对比打分
- 生成灯光评价报告/评分表

**指标体系**：近光灯 10 项 + 远光灯 6 项，共 12 项指标

---

## 评价指标

### 一、灯光实物图评价（3 项）

> **评价依据**：通过灯光实物图观察光型形态、截止线质量、杂散光情况，评估光型本身的品质

#### 1. 均匀性（近光 20% / 远光 15%）

**核心定义**：中心亮区是否明确，从亮区到边缘亮度连续递减，无明显暗区或亮斑。必须分区检查（左/右两区），不能只看整体印象。

| 分数 | 标准 |
|------|------|
| 5 分（优秀） | 两区完全一致，中心到边缘连续递减，零暗区零亮斑 |
| 4 分（良好） | 整体均匀，分区检查发现极轻微明暗差异，不影响整体感 |
| 3 分（合格） | 存在可见暗区，面积约 ≤ 光型面积 1/8，对驾驶有轻微影响 |
| 2 分（差） | 暗区明显，面积约 1/4，左右亮度差异明显，影响局部照明 |
| 1 分（极差） | 大面积暗区或左右严重不对称，照明功能基本丧失 |

#### 2. 下边界整齐度（近光 5% / 远光 5%）

**核心定义**：截止线笔直度 + 拐角明显程度 + 下方边界整洁度（拐角越明显、越突兀 → 分越低）

| 分数 | 近光标准 | 远光标准 |
|------|----------|----------|
| 5 分（优秀） | 截止线全程笔直如刀切，无拐角痕迹，下方边界绝对干净 | 截止线全程笔直如刀切，无拐角痕迹 |
| 4 分（良好） | 截止线整体笔直，拐角处有轻微痕迹但不突兀，下方边界整洁 | 截止线整体笔直，拐角处有轻微痕迹但不突兀 |
| 3 分（合格） | 截止线有可见波浪起伏，拐角处痕迹较明显，下方有轻微晕染 | 截止线有可见波浪起伏，拐角处痕迹较明显 |
| 2 分（差） | 截止线弯曲或变形，拐角明显圆弧化，下方有明显向上晕染 | 截止线弯曲或变形，拐角明显圆弧化 |
| 1 分（极差） | 截止线不可辨，拐角完全圆弧化，下方大面积晕染 | 截止线不可辨，拐角完全圆弧化 |

#### 3. 杂散光（近光 10% / 远光不适用）

**核心定义**：截止线上方光晕宽度 + 亮度，结合车头前方光源分布判断（引擎盖前方路面是否泛白发雾）

| 分数 | 标准 |
|------|------|
| 5 分（优秀） | 截止线上方完全纯黑，车头前方路面零泛白 |
| 4 分（良好） | 极微弱光晕（<1°），仔细观察才可察觉，路面基本干净 |
| 3 分（合格） | 可辨光晕带（1°~3°），路面有轻微泛白 |
| 2 分（差） | 光晕带较宽（3°~5°），路面泛白发雾，致眩风险 |
| 1 分（极差） | 严重漏光，大面积光晕（>5°），致眩 |

#### 3.5 眩目安全（仅近光 8%）

**核心定义**：截止线高度控制精度 + 上溢光线范围和亮度，评估对向驾驶员的致眩风险。截止线越高、上溢越宽 → 眩目风险越大。

| 分数 | 标准 |
|------|------|
| 5 分（优秀） | 截止线高度控制极佳，上溢光线极微，对向驾驶员零致眩风险 |
| 4 分（良好） | 截止线高度控制良好，有极轻微上溢但不影响对向来车 |
| 3 分（合格） | 截止线高度略有偏高，上溢光线可辨，对向来车有轻微不适 |
| 2 分（差） | 截止线高度明显偏高，上溢光线较宽，致眩风险较大 |
| 1 分（极差） | 截止线高度失控，大面积上溢光，严重致眩 |

#### 4. 远近光一致性（仅远光 10%）

**核心定义**：90m 处远近光过渡是否平滑自然，有无割裂感

| 分数 | 标准 |
|------|------|
| 5 分（优秀） | 90m 处过渡极其平滑自然，远近光衔接无感 |
| 4 分（良好） | 基本自然，略有梯度但可接受 |
| 3 分（合格） | 梯度不均，近亮远暗较明显 |
| 2 分（差） | 严重割裂，亮暗突兀 |
| 1 分（极差） | 完全割裂，远近光形同两个独立光型 |

### 二、鸟瞰伪彩图评价

> **评价依据**：通过鸟瞰伪彩图观察光型的横向覆盖、纵向延伸和近场照度，评估照明范围、照射距离和路面照度

#### 5. 近场暗区（仅近光 5%）

**核心定义**：车头前 2~5m 区域照度是否充足，有无明显暗区

| 分数 | 标准 |
|------|------|
| 5 分（优秀） | 车头前均匀充足照明，零暗区，近场照度极佳 |
| 4 分（良好） | 近场整体可接受，有极轻微暗区 |
| 3 分（合格） | 暗区明显，近场照明偏弱，约 2~5m 区域偏暗 |
| 2 分（差） | 明显暗区，近处看不清路面，存在安全隐患 |
| 1 分（极差） | 大面积死黑，近场照明严重缺失，安全隐患极大 |

#### 6. 左侧宽度（仅近光 10%）

**核心定义**：路左侧可视距离

| 分数 | 标准 |
|------|------|
| 5 分（优秀） | 路左侧远处清晰可辨，可视距离极远 |
| 4 分（良好） | 左侧可视基本充足 |
| 3 分（合格） | 左侧可视偏短，远处辨识度降低，有盲区 |
| 2 分（差） | 路左侧几乎无可视，存在安全隐患 |
| 1 分（极差） | 路左侧无照明，严重安全隐患 |

#### 7. 右侧宽度（仅近光 10%）

**核心定义**：路右侧可视距离

| 分数 | 标准 |
|------|------|
| 5 分（优秀） | 50m 外右侧充足，清晰可见，可视距离极远 |
| 4 分（良好） | 右侧可视基本充足 |
| 3 分（合格） | 右侧可视偏暗/不足，远处辨识度降低 |
| 2 分（差） | 路右侧几乎无可视 |
| 1 分（极差） | 路右侧无照明，严重隐患 |

#### 8. 左侧照度（近光 10% / 远光 15%）

**核心定义**：左侧路面照度和障碍物检测能力

| 分数 | 近光标准（5~50m） | 远光标准（90m 内） |
|------|-------------------|-------------------|
| 5 分（优秀） | 左侧照度极高，清晰检测一切障碍物 | 左侧照度极高，行人检测能力优秀 |
| 4 分（良好） | 左侧基本覆盖，检测正常 | 左侧基本覆盖，检测正常 |
| 3 分（合格） | 左侧偏暗，检测较困难 | 左侧偏暗，检测能力下降 |
| 2 分（差） | 左侧照度不足，检测困难 | 左侧照度明显不足 |
| 1 分（极差） | 左侧路面无照明 | 左侧路面无照明 |

#### 9. 右侧照度（近光 10% / 远光 15%）

**核心定义**：右侧路面照度和障碍物检测能力

| 分数 | 近光标准（5~50m） | 远光标准（90m 内） |
|------|-------------------|-------------------|
| 5 分（优秀） | 右侧照度极高，检测能力优秀 | 右侧照度极高，行人检测能力优秀 |
| 4 分（良好） | 右侧基本覆盖，检测正常 | 右侧基本覆盖，检测正常 |
| 3 分（合格） | 右侧偏暗，检测较困难 | 右侧偏暗，检测能力下降 |
| 2 分（差） | 右侧照度不足 | 右侧照度明显不足 |
| 1 分（极差） | 右侧路面无照明 | 右侧路面无照明 |

#### 10. 光照度（仅近光 20%）

**核心定义**：路面最大照度，光量是否充沛

| 分数 | 标准 |
|------|------|
| 5 分（优秀） | 路面最大照度极高，光量充沛，强烈光明感 |
| 4 分（良好） | 照度足够，满足驾驶需求 |
| 3 分（合格） | 照度不足，光量偏暗 |
| 2 分（差） | 照度明显不足，路面偏暗 |
| 1 分（极差） | 照度近乎为零，照明功能丧失 |

#### 11. 远度（仅远光 40%）

**核心定义**：截止线远端锐利度和远近场亮度梯度

| 分数 | 标准 |
|------|------|
| 5 分（优秀） | 截止线远端扎实锐利，远处亮度无衰减，远近场梯度完美平滑 |
| 4 分（良好） | 远端略有软化但亮度充足，远近场梯度略陡但可接受 |
| 3 分（合格） | 远端偏暗，有轻微断尾，梯度偏陡 |
| 2 分（差） | 远端消失/断裂，远处融入黑暗 |
| 1 分（极差） | 远端完全消失，光型严重缩短 |

## 三、评级标准（近光 / 远光统一）

**评级流程**：逐项打分（1~5 分）→ 加权计算总分 → 惩罚规则校验 → 确定最终评级

| 评级 | 加权总分 | 附加条件 |
|------|----------|----------|
| ⭐ 优秀 | ≥ 4.2 | 无 ≤ 2 分项 |
| ✅ 良好 | ≥ 3.5 | 无 1 分项 |
| ⚠️ 合格 | ≥ 2.5 | 无 1 分项 |
| ❌ 差 | < 2.5 | 或存在 1 分项 |

---

## 四、评分计算示例

**示例：近光灯评分**

| # | 指标 | 得分 | 权重 | 加权得分 |
|---|------|------|------|----------|
| 1 | 均匀性 | 4 | 20% | 0.80 |
| 2 | 下边界整齐度 | 4 | 5% | 0.20 |
| 3 | 杂散光 | 4 | 10% | 0.40 |
| 4 | 眩目安全 | 4 | 8% | 0.32 |
| 5 | 近场暗区 | 3 | 5% | 0.15 |
| 6 | 左侧宽度 | 4 | 10% | 0.40 |
| 7 | 右侧宽度 | 4 | 10% | 0.40 |
| 8 | 左侧照度 | 3 | 10% | 0.30 |
| 9 | 右侧照度 | 3 | 10% | 0.30 |
| 10 | 光照度 | 4 | 12% | 0.48 |

加权总分 = 0.80 + 0.20 + 0.40 + 0.32 + 0.15 + 0.40 + 0.40 + 0.30 + 0.30 + 0.48 = **3.75**

惩罚校验：无任何项触发惩罚 → 无评级上限限制

通用校验：3 分占比 = 3/10 = 30%（<70%），存在 4 分项 → 通过

最终评级：3.75 ≥ 3.5 且无 1 分项 → **✅ 良好**

## 五、防失真与校验规则

> **惩罚判定流程（按优先级执行）**
> ① 先查惩罚表 → 命中「一票降级」→ 锁定评级上限为「合格」
> ② 再查「等级封顶」→ 进一步锁定评级上限
> ③ 最后查通用校验 → 命中则建议重审，不改评级

### 近光灯一票降级

| 条件 | 惩罚 |
|------|------|
| 杂散光 = 1 | 整灯最高「合格」 |
| 左侧宽度 = 1 | 整灯最高「合格」 |
| 近场暗区 = 1 | 整灯最高「合格」 |

### 近光灯等级封顶

| 条件 | 惩罚 |
|------|------|
| 均匀性 ≤ 2 | 整灯最高「合格」 |
| 左/右宽度 ≤ 2 | 整灯最高「合格」 |
| 下边界整齐度 ≤ 2 | 整灯最高「良好」 |

### 远光灯一票降级

| 条件 | 惩罚 |
|------|------|
| 远度 = 1 | 整灯最高「合格」 |

### 远光灯等级封顶

| 条件 | 惩罚 |
|------|------|
| 左/右照度（90m 内）≤ 2 | 整灯最高「合格」 |
| 均匀性 = 1 | 整灯最高「合格」 |

### 通用校验（中央趋势审查，不改评级，仅建议重审）

1. **中央趋势偏差检查**：3 分占比 ≥ 70% → 建议重审
2. **档位拉开检查**：无 1 分且无 5 分 → 建议拉开区分档位
3. **多灯同档检查**：多灯对比时所有灯落入同一评级 → 建议重审

## 八、评价术语规范

| 术语 | 含义 |
|------|------|
| 截止线 | 近光灯明暗分界线，是灯光品质的核心判断对象 |
| 扇面角度 | 光型左右展开的横向覆盖范围，角度越大覆盖越广 |
| 远近场梯度 | 从近处到远处的亮度变化斜率，越平滑越好 |
| 远近光一致性 | 远光灯与近光灯在重叠区域（约90m处）的亮度过渡自然度 |
| 近场暗区 | 车头前方 2~5m 范围内照度不足的区域 |
| 断尾 | 截止线远端亮度骤降，呈断裂状消失 |
| 光晕带 | 截止线上方的残余光线带，是杂散光的主要表现 |
| 热点 | 光型中的局部高亮区域，影响均匀性 |
| 晕染 | 截止线下方边界向上方扩散的现象 |
| 泛白发雾 | 车头前方路面因杂散光导致的白色雾状反射 |
| 波浪起伏 | 截止线不够笔直，呈微小波浪状（3 分下边界特征） |
