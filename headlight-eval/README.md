# 前照灯主观评价系统

> **说明**：本仓库为脱敏版本。AI 评分已从内部平台模型改为本地 Ollama 视觉模型（默认 `qwen2.5vl:7b`，
> shim 见 `shared/ai-proxy.js`，可用 `OLLAMA_URL` 环境变量覆盖）。引导页背景视频已移除。

## 基本信息

- 模块ID：headlight-eval（用于URL路径 /headlight-eval/）
- 所属分组：smart（智能硬件组）
- 一句话描述：AI 自动评分的前照灯主观评价系统，上传图片即可自动出分、生成报告、多灯对比
- 版本：v4.0 · 依据《前照灯主观评价标准 2026.07》

## 功能说明

### 核心流程

1. 用户输入灯具名称、选择灯型（近光/远光）
2. 上传灯光实物图 → AI 自动评价：均匀性、下边界整齐度、杂散光、近场暗区
3. 上传鸟瞰伪彩图 → AI 自动评价：左/右侧宽度、左/右侧照度、光照度、远度、远近光一致性
4. 评分完成后，自动生成量化评价报告（含防失真惩罚规则检查）
5. 支持批量上传多组灯具、多灯横向对比、雷达图展示、JSON/HTML 报告导出

### 评价指标（共 11 项）

#### 近光灯指标（10 项，总权重 100%）

| 指标 | 图片类型 | 权重 | 说明 |
|------|---------|------|------|
| 均匀性 | 实物图 | 20% | 中心到边缘亮度递减连续性，有无暗区或亮斑 |
| 下边界整齐度 | 实物图 | 5% | 截止线笔直度、拐角明显程度、下方边界整洁度 |
| 杂散光 | 实物图 | 10% | 截止线上方光晕宽度、路面有无泛白发雾 |
| 眩目安全 | 实物图 | 8% | 截止线高度控制、上溢光线范围、对向致眩风险 |
| 近场暗区 | 伪彩图 | 5% | 车头前 2~5m 区域照度是否充足 |
| 左侧宽度 | 伪彩图 | 10% | 路左侧可视距离 |
| 右侧宽度 | 伪彩图 | 10% | 路右侧可视距离 |
| 左侧照度 | 伪彩图 | 10% | 5~50m 左侧照度、障碍物检测能力 |
| 右侧照度 | 伪彩图 | 10% | 5~50m 右侧照度、障碍物检测能力 |
| 光照度 | 伪彩图 | 12% | 路面最大照度，光量是否充沛 |

近光灯满分 = 20+5+10+8+5+10+10+10+10+12 = 100%

#### 远光灯指标（6 项，总权重 100%）

| 指标 | 图片类型 | 权重 | 说明 |
|------|---------|------|------|
| 均匀性 | 实物图 | 15% | 中心到边缘亮度递减连续性 |
| 下边界整齐度 | 实物图 | 5% | 截止线笔直度、拐角明显程度 |
| 左侧照度 | 伪彩图 | 15% | 90m 内左侧照度、行人检测能力 |
| 右侧照度 | 伪彩图 | 15% | 90m 内右侧照度、行人检测能力 |
| 远度 | 伪彩图 | 40% | 截止线远端锐利度、远近场梯度平滑度 |
| 远近光一致性 | 实物图 | 10% | 90m 处远近光过渡自然度 |

远光灯满分 = 15+5+15+15+40+10 = 100%

### 评分标准

采用 1~5 分制（5=优秀，4=良好，3=合格，2=差，1=极差），各指标评分标准详见前端页面「评分标准」展开面板。

### 评级体系

| 评级 | 总分 | 附加条件 |
|------|------|----------|
| ⭐ 优秀 | ≥ 4.2 | 无 ≤ 2 分项 |
| ✅ 良好 | ≥ 3.5 | 无 1 分项 |
| ⚠️ 合格 | ≥ 2.5 | 无 1 分项 |
| ❌ 差 | < 2.5 | 或存在 1 分项 |

### 防失真规则（按优先级执行）

#### 近光灯一票降级
- 杂散光 = 1 → 整灯最高「合格」
- 左侧宽度 = 1 → 整灯最高「合格」
- 近场暗区 = 1 → 整灯最高「合格」

#### 近光灯等级封顶
- 均匀性 ≤ 2 → 整灯最高「合格」
- 左/右宽度 ≤ 2 → 整灯最高「合格」
- 下边界整齐度 ≤ 2 → 整灯最高「良好」

#### 远光灯一票降级
- 远度 = 1 → 整灯最高「合格」

#### 远光灯等级封顶
- 左/右照度（90m 内）≤ 2 → 整灯最高「合格」
- 均匀性 = 1 → 整灯最高「合格」

#### 中央趋势审查（通用，不改评级，仅建议重审）
- 3 分占比 ≥ 70% → 存在中央趋势偏差，评分可能失真
- 无 1 分且无 5 分 → 建议拉开区分档位

## 管理员操作

### server.js 挂载

```javascript
const headlightEvalRoutes = require('./modules/smart/headlight-eval/routes');
app.use('/headlight-eval', moduleAuth('headlight-eval'), headlightEvalRoutes);
```

### 需要安装的 npm 包

无额外依赖，使用平台已有的 express 即可。

### AI 助手接入

请在 ai-assistant/routes.js 的 SYSTEM_PROMPT 中添加：

【平台模块路径】加一行：
- /headlight-eval/ — 前照灯主观评价系统（AI 自动评分、多灯对比、报告导出）

【新增 action】：
action名：headlight_eval
参数：
- name: 灯具名称（字符串）
- type: 灯型（"lowbeam" 近光 / "highbeam" 远光）
触发场景：用户说"帮我评价近光灯"、"灯光打分"时触发

【前端已自行注册 window.__aiActions['headlight_eval']，无需改 ai-widget.js】

### 数据目录

需要在顶层 data/ 下创建：data/headlight-eval/

## 接口文档

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/analyze | POST | 图片 AI 分析打分，接收 {imageBase64, metric, lightType, criteria}，返回 {score, reason, confidence}（多模态模型 qwen2.5vl:7b（本地 Ollama 视觉模型）） |
| /api/save | POST | 保存评价记录（字段白名单 + 1MB 上限 + 归属记录），返回 {success, id} |
| /api/history | GET | 查询历史记录（最近 50 条） |
| /api/record/:id | GET | 获取单条记录详情 |
| /api/record/:id | DELETE | 删除记录（仅属主可删，含 id 格式校验防路径穿越） |

## 前端功能

- **引导页**：系统介绍，含三大功能亮点（批量上传、雷达对比、防失真规则）
- **批量上传**：支持多组灯具同时上传，每组含实物图 + 伪彩图，可选择灯型
- **AI 评分仪表盘**：逐指标环形仪表盘，实时展示评分进度
- **评价报告**：含加权总分环形图、分项评分条形图、详细评分表、惩罚触发提示
- **多灯对比**：综合排名卡片、逐项水平条形对比、多维雷达图（Chart.js）
- **导出**：支持单灯/批量导出文本报告、JSON 数据导出/导入、HTML 网页报告导出
