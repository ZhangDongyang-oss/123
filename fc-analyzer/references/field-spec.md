## 严重度规则（#11 问题严重度）

| 级别 | 判断标准 | 灯具域典型场景 |
|------|---------|---------------|
| **S** | 安全/法规/不可交付/召回 | 灯光法规不合格（配光不达标）、前灯/尾灯完全不亮、刹车灯失效、转向灯不工作、影响行车安全 |
| **A** | 主要功能失效/大面积外观/量化偏差>30% | 前灯亮度衰减>30%、灯壳大面积开裂、灯罩严重发黄（>50%面积）、尾灯大面积进水、色温偏差超法规限值。**默认值** |
| **B** | 局部功能降级/可见异常/量化偏差10%-30% | 局部光衰（10%-30%）、轻微起雾（24h内可消散）、小面积黄变、配光偏移、密封胶轻微老化。 |
| **C** | 轻微异常/主观感知/工程裕度内 | 轻微色差、主观亮度感觉偏暗但满足法规、工艺微瑕、装配微小间隙 |

### 灯具域线索词速查

- 不亮/失效/法规不合格/配光不达标 → **S**
- 严重衰减/大面积进水/开裂/色温超限 → **A**
- 轻微衰减/起雾/局部黄变/密封老化 → **B**
- 色差/主观感/工艺微差 → **C**

### VIIM 取值映射（2026-08-21 契约漂移）

内部分级仍用单字母 S/A/B/C 判断，建单时由 `lighting_extractor` / `viim_client` 映射为 VIIM 完整取值：

| 内部级 | VIIM 取值（cf10621） |
|---|---|
| S | S-非常重要（安全/法规/抛锚） |
| A | A-重要 |
| B | B-一般重要 |

## 描述生成模板（#19 描述）

按下列顺序扩写用户的一句话（保留原词，不编造未提及信息）：

1. **现象**：复述灯具零件 + 出现什么问题（用户原话标准化）
2. **条件**：触发条件（温度/湿度/振动/时间/工况），无则省略
3. **量化**：数值偏差（若用户给了，如"亮度衰减25%"、"色温偏移200K"）
4. **影响**：对外观/功能/法规/客户感知的影响
5. **范围**：是否批量/偶发/单车，若用户未说则省略

**禁止**：添加用户未提及的零件、根因猜测、解决方案。

**灯具域描述示例**：
```
前灯透镜在高温85°C环境下持续工作4小时后，亮度衰减约25%，导致近光照射距离缩短，
影响夜间行车安全。该问题在批量试制车上均可复现。
```

## 灯具域特殊注意事项

### 1. 法规关联
灯具问题需特别注意是否涉及 GB 4785（汽车及挂车外部照明和光信号装置的安装规定）、
GB 25991（汽车用LED前照灯）、ECE R112/R7/R6 等法规。涉及法规的问题严重度至少为 **A**，可能为 **S**。

### 2. 光学指标
灯具域常用量化指标：
- 光通量（lm）/ 照度（lux）
- 色温（K）/ 色坐标（CIE xy）
- 配光（近光截止线位置、远光照射距离）
- 点亮寿命（h）/ 衰减百分比

### 3. 环境试验条件
- 高温：85°C / 105°C
- 低温：-40°C
- 温度冲击：-40°C ↔ 85°C
- 盐雾：5% NaCl，35°C
- 振动：随机振动谱
- 防水：IPX7/IPX9K
- UV老化：SAE J576
