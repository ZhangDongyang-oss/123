# Ruisearch 使用说明
## 一、是什么
一个集成 17 个搜索平台的 Claude Code skill，覆盖网页搜索、股票行情、社交媒体、视频、GitHub、招聘、专利检索，支持生成调研报告和多种文档格式。
## 二、怎么用
### 2.1 自动触发
对话中提到以下关键词时自动激活，无需手动调用
| 场景 | 自然触发词 |
| --- | --- |
| 通用搜索 | "搜一下""帮我查""找一下 XX" |
| 股票行情 | "股价""行情""财报""今天涨跌" |
| 调研报告 | "调研""竞品分析""市场分析""整理报告" |
| 社交媒体 | "小红书搜""推特上""B站找""Reddit" |
| 视频内容 | "YouTube 上""播客""字幕""转录" |
| GitHub | "搜个仓库""找下这个 issue" |
| 专利 | "专利检索""查新""技术壁垒" |

**不会自动触发**于纯聊天、写代码、Git 操作、文件编辑
### 2.2 手动调用
任何时候都可以直接敲 `/ruisearch` + 你想查的内容
### 2.3 切换格式
默认飞书紧凑排版，随时可以说"用标准 Markdown"或"转成 Word 格式"切换
## 三、能做什么
### 3.1 股票行情
查股价走腾讯实时接口，追问原因走 Exa 深度搜索
| 操作 | 触发方式 | 工具 |
| --- | --- | --- |
| 查价格 | "小米股价""恒生指数多少" | 腾讯行情 API |
| 查原因 | "为什么跌""什么原因涨" | Exa 语义搜索 |
| 查财报 | "小米 Q2 财报""腾讯营收" | Exa 语义搜索 |

- **查价格**：返回当前价、涨跌幅、今开、最高最低、成交量，表格展示
- **查原因**：搜索新闻、研报、市场分析，整合多来源后给出结构化分析
- **查财报**：提取关键财务数据，对比预期和去年同期

## 四、两种模式
### 4.1 快速查询（默认）
- 触发："查一下""搜一下""XX 股价"
- 流程：单次搜索 → 直接在聊天里回答
- 产出：不生成文件，标注来源和置信度
- 中途可以追加"整理成报告"升级为完整报告
### 4.2 完整报告
- 触发："调研""分析报告""竞品对比""整理报告"
- 流程：搜索两遍 → 分析一遍 → 输出文件
- 产出：`./outputs/` 目录下生成 Markdown 文件
- 格式：默认飞书紧凑格式，可切换标准 MD 或 Word 友好格式

> 拿不准时默认走快速查询，需要深度时再升级
## 五、三种输出格式
| 格式 | 触发词 | 特点 |
| --- | --- | --- |
| 飞书紧凑 | 默认 | 紧凑排版，适配飞书渲染器 |
| 标准 Markdown | "标准 Markdown" | CommonMark，适合 GitHub/本地 |
| Word 友好 | "Word 格式""docx" | 面向 pandoc 转换，标题连续不跳级 |

- **飞书紧凑**：标题和内容间无空行，表格 ≤ 4 列，每格 ≤ 30 字，不加粗、不用 HTML——这些是飞书渲染器的限制，非审美偏好。在非飞书环境输出时可以放松
- **标准 Markdown**：段落间有空行，支持多级嵌套列表，适合 GitHub README 和通用文档
- **Word 友好**：标题层级连续，表格有完整表头，可用 pandoc 一键转 docx
## 六、典型用法示例
### 场景 1：快速查行情
```
你：查一下小米今天股价
→ 自动返回当前价、涨跌幅、振幅、成交量（表格）
你：为什么跌？
→ 自动搜索新闻 + 研报，给出多维度分析
```
### 场景 2：竞品调研
```

→ 触发完整报告模式

→ 含市场概况、竞争格局、技术趋势、关键结论
```
### 场景 3：社交媒体热点
```
你：小红书搜一下今年露营装备推荐
→ 走小红书 CLI 搜索，返回热门帖子和趋势
你：推特上 AI 芯片最近有什么讨论？
→ 走推特 CLI 搜索，返回相关推文和情绪分析
```
### 场景 4：代码/GitHub
```
你：搜个 Python 异步爬虫的开源项目
→ 走 gh CLI 搜索 GitHub 仓库，按星数排序
```
## 七、怎么知道它用对了
### 7.1 看状态标注
每次启动时会在思考中标注当前搜索链路
| 标注 | 含义 |
| --- | --- |
| `[Exa]` | Exa 语义搜索可用，最佳状态 |
| `[WebSearch]` | Exa 不可用，已降级为内置搜索 |
### 7.2 看来源标注
每次回答末尾会标注数据来源，例如：
```
> 数据来源：腾讯行情 API（qt.gtimg.cn）
> 数据来源：Exa → 钜亨网、36氪、花旗研报
```
## 八、常见问题
**Q：为什么不是每次都能自动触发**
A：自动触发依赖 description 中的关键词匹配。如果模型没识别到，手动 `/ruisearch` 即可。这比过度触发（不该搜索时也搜索）要好
**Q：Exa 是什么，需要额外配置吗**
A：Exa 是一个 AI 语义搜索引擎，擅长英文和技术内容。首次使用 ruisearch 时会自动检查并配置，唯一需要你参与的是浏览器 OAuth 认证（免费）
**Q：除了 Exa 还需要装什么**
A：Exa 和腾讯行情 API 是零依赖的。小红书/推特/B站/Reddit/抖音等社交媒体需要对应的 CLI 工具（pipx install），首次触发对应平台时会提示安装。不触发就不需要装
**Q：调研报告能写多深**
A：快速查询是单次搜索，深度有限。完整报告模式（说"调研"触发）会搜索两遍 + 分析一遍，产出结构化 Markdown 文件。需要更深可以追加"再挖一下""补充 XX 方面"继续迭代
**Q：怎么指定输出格式**
A：说"用标准 Markdown"或"转 Word 格式"即可实时切换。什么都不说就默认飞书紧凑格式
> 还有其他问题？直接问，ruisearch 会自己回答关于自己的问题
