# 专利法律状态分级与风险评估规则

## 核心逻辑：DRE要的不是"专利有多少件"，而是"哪些会让我栽跟头"

```
已授权专利 = 立即生效 = 必须规避或获得许可
在审申请   = 潜在风险 = 需持续跟踪
驳回/撤回 = 不构成风险 = 仅历史参考
空白区     = 我方可布局 = 战略机会
```

---

## 法律状态三级分类

### 🟢 空白区（竞对无保护）

**定义**：检索范围内，竞对在某个技术方向**没有任何相关专利**

**DRE意义**：
- 我方可在该方向自由布局专利
- 选型时可优先考虑无封锁的技术路线

**报告呈现**：单列"技术空白区"小节

---

### 🟡 在审专利（潜在风险）

**定义**：申请已公开但**尚未授权**（实质审查中或等待授权）

**DRE意义**：
- **不立即构成侵权**，但授权后会成为风险
- 需持续跟踪审查进展（可定期重新检索）
- 部分在审申请可能在授权前被驳回或主动撤回

**风险等级细分**：

| 授权前景 | 风险等级 | 应对 |
|---|---|---|
| 高（核心技术+新申请） | 中 | 紧密跟踪，提前考虑规避设计 |
| 中（一般技术+普通申请） | 低 | 常规跟踪即可 |
| 低（边缘技术+早年申请） | 低 | 关注但不投入资源 |

**报告呈现**：单列"在审专利"表，含"授权前景预判"列

---

### 🔴 已授权专利（立即生效）

**定义**：已经下证、专利权**当前有效**的专利

**DRE意义**：
- **立即构成侵权风险**——只要产品落入权利要求保护范围，竞对可起诉
- 必须**逐件评估**与"我方方案"的关系
- 规避难度大时考虑**获得许可**或**改设计**

**报告呈现**：单列"已授权专利"表，含"保护范围"+"规避建议"两列

## 同族追踪规则（防"漏网分案"）

### 为什么要做同族追踪？

**说明**：同族追踪是防漏检的关键步骤——某竞对可能仅在中国公开了少量专利，但通过 PCT 同族在其母国或其他法域有大量已授权专利。不同族仅看中国专利会严重低估风险。

### 同族识别方法

| 同族类型 | 识别方法 |
|---|---|
| **PCT国际申请族** | 同PCT申请号 → 各国国家阶段 |
| **优先权族** | 同优先权号 → 母案+分案 |
| **分案族** | 母案公开号 → 分案申请号 |
| **中国同族** | 美国专利号 → CNIPA查中国同族 |

### 同族汇总表（格式示例，全部为虚构占位符）

```
| 申请族 | 中国专利 | 美国同族 |
| --- | --- | --- |
| 族1：<方向A> | CN1XXXXX+CN2XXXXX+CN3XXXXXA | US1XXXXXXXXB1等 |
| 族2：<方向B> | CN4XXXXX+CN5XXXXXA+CN6XXXXXA | US2XXXXXXXXB2等3件 |
```

## 风险等级判定矩阵（综合判断）

| 已授权 | 在审 | 与我方方案关系 | 最终风险 |
|---|---|---|---|
| ✓ | - | 直接覆盖核心特征 | 🔴 高风险 |
| ✓ | - | 边缘相关 | 🟡 中风险 |
| - | ✓ | 直接覆盖核心特征 | 🟡 中风险 |
| - | ✓ | 边缘相关 | 🟢 低风险 |
| - | - | 无相关专利 | 🟢 空白区 |

---

## 风险规避建议类型（给DRE的实操选项）

| 规避类型 | 适用场景 | 示例 |
|---|---|---|
| **改技术路线** | 竞对覆盖了我方原方案 | 用并联LED替代串联LED |
| **改触发条件** | 竞对保护特定控制逻辑 | 用不同信号触发 |
| **改结构布置** | 竞对保护特定物理结构 | 避免完全相同的结构 |
| **获得许可** | 规避成本高于许可成本 | 与竞对谈判交叉许可 |
| **法律意见** | 高风险但方案有差异化空间 | 申请专利律师出具FTO意见 |

## AI不替代律师的红线

⚠️ **以下判断必须由专利代理人签字，不在Skill输出范围**：

- 权利要求技术特征逐一比对（侵权判定）
- 等同原则适用（专利侵权判定）
- 专利有效性分析（无效宣告）
- 商标/版权/商业秘密等其他IP风险

**Skill只输出**：风险提示清单 + 推荐行动方向，**不输出**：侵权判定结论。
