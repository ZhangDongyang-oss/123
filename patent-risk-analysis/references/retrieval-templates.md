# DRE风险视角 - 检索提问模板

## 与"挖自家专利"检索的区别

| 维度 | 挖自家（disclosure-forge） | 查竞对（本skill）|
|---|---|---|
| 提问目的 | 找差异化点（避开已有） | 找风险点（识别封锁） |
| 提问风格 | "我的方案有什么不同" | "竞对覆盖了哪些保护点" |
| 关心字段 | 区别特征、原理差异 | 权利要求、保护范围、同族 |
| 漏检代价 | 申请被驳回 | 量产被起诉 |

## CNIPA关键词检索模板（每次一词）

按核心技术方向**拆词**检索，每词单独调用一次：

### 模板1：竞对 + 技术方向
```
python cnipa_epub_search.py "<竞对中文名> <技术方向词1>"
python cnipa_epub_search.py "<竞对中文名> <技术方向词2>"
python cnipa_epub_search.py "<竞对中文名> <技术方向词3>"
python cnipa_epub_search.py "<竞对英文名> <英文技术关键词>"
```

### 模板2：技术方向（无竞对）
```
python cnipa_epub_search.py "DMS EC镜片"

python cnipa_epub_search.py "驾驶员监测 摄像头"
```

### 模板3：我方方案对照（用于FTO）
```

```

## Exa语义检索模板（概念描述，不是堆砌关键词）

### 中文查询（覆盖中国专利）
```
"在汽车内后视镜中集成驾驶员监测摄像头与近红外LED光源，通过EC镜片同时实现防眩目和DMS光路"
```

### 英文查询（覆盖国际专利）
```
"integrated driver monitoring system in interior rearview mirror with NIR illumination through electrochromic glass"
```

**关键技巧**：描述**技术方案概念**而不是堆砌关键词。Exa擅长概念匹配，不擅长关键词命中。

## 关键词拆分策略

### 第一层：竞对名称（必查）
- 公司中文名 + 英文名 + 常见别名
- 例：<竞对中文名> / <竞对英文名> / <子公司/曾用名>

### 第二层：技术方向（3-5个）
- 技术功能词：DMS / OMS / 后视镜 / 流媒体
- 技术特征词：近红外 / LED / 摄像头 / EC镜片
- 应用场景词：驾驶员监测 / 乘员监测 / 防眩目

### 第三层：特征细节（用于FTO对照）
- 具体技术实现：940nm / 脉冲率 / 半透反射
- 结构创新：one-box集成 / 摄像头位置

## 检索质量自检（合并结果后做）

| 检查项 | 通过标准 |
|---|---|
| 命中数量 | 至少5件相关专利 |
| 时间分布 | 包含近2年专利（识别新布局） |
| 申请人分布 | 主要竞对占主体（避免被无关专利淹没） |
| 技术覆盖 | 覆盖核心技术方向的3个以上维度 |

**任一不通过** → 调整关键词，扩展检索；如调整后仍不佳 → 触发智慧芽backup。

---

## 不该做的事

- ❌ 用单个长query做关键词检索（容易漏检）
- ❌ 只查中国专利（漏国际风险）
- ❌ 跳过Exa语义（漏概念盲区）
- ❌ 不核实法律状态直接给风险等级
- ❌ 漏掉分案/同族（漏掉就是漏报风险）
